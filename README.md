# FIT CHECK — Studio Edition
> **Your style. Your rules.**

FIT CHECK is a premium, gender-inclusive personal fashion and styling studio application. It helps individuals discover, create, organize, and plan intentional outfits based on mood, weather, occasion, profession, dress code, day of the week, and aesthetic.

---

## Highlights

* **Editorial Luxury Aesthetic**: Warm ivory (`#F7F4EF`), soft cream (`#EEE8DF`), deep charcoal (`#211F1E`), and rich burgundy (`#702B40`) palette paired with `Playfair Display` and `DM Sans` typography.
* **Gender-Inclusive Studio**: No gendered assumptions about silhouettes, occupations, body types, colors, or aesthetics.
* **My Closet (Digital Wardrobe)**: Full garment cataloging across Tops, Bottoms, One-Piece, Outerwear, Footwear, and Accessories. Features camera/device photo uploads with client-side canvas compression, preset photo library, search, filtering, and favorites.
* **Style Lab**: Interactive 7-slot composition board with drag-and-drop support, silhouette harmony analysis, "Complete the Look" intelligent accessory matching, and **Export Board as PNG**.
* **Personal Styling Assistant**: Multi-criteria rules-based styling wizard generating **"Style My Closet"** recommendations with editorial explanations alongside **"Discover New Looks"** inspiration.
* **Weekly Planner**: Visual 7-day fashion calendar (Monday to Sunday) with event scheduling, location tags, duplication, and week navigation.
* **My Lookbook**: Personal fashion portfolio organized into collections with canvas PNG exports and native Web Share integration.
* **The Fit Challenge**: 9 rotating styling challenges with submission tracking.
* **Persistence & Backup**: All data stored locally in `localStorage` with JSON export/import backup functionality.

---

## Tech Stack

* **HTML5**: Semantic application shell with modal systems and accessibility attributes.
* **CSS3**: Custom design system, responsive breakpoints, transitions, and print/export styles.
* **Vanilla JavaScript (ES6+)**: Pure client-side state management, rules engine, canvas export, and image compression.
* **Zero External Frameworks**: No React, Vue, Angular, or backend required.

## Getting Started

Simply clone or download this repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/SO-JourneyToDataSymphony/fit-check.git
cd fit-check
```

Open `index.html` directly in Chrome, Edge, Safari, or Firefox.
